# Library Management System

A concurrent library management system implemented in C using socket programming and POSIX threads.

## Overview
This project provides a client-server based library management system with multi-client support, user authentication, and concurrent access handling.

## Planned Features
- Multi-threaded TCP server with POSIX threads
- Role-based access control (Admin and Member)
- Book management (search, borrow, return, add, delete)
- Member account administration
- Mutex-protected file storage
